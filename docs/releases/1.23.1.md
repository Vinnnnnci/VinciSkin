### 新增

- **诊断包**。设置 → 关于 →「获取帮助…」、设置 → 通用 → 诊断卡片里的「生成诊断包」，或者任意一条错误提示底部的「生成诊断包」，都能打开它。它把日志、系统检查、设置、mod 列表、注入器状态和最近几次事故打包成一个 zip，保存前可以逐个文件看内容。勾选「带上 League 的游戏日志」会再加上最近一局的那份日志（前提是那次记下了）。
- 诊断包里的 `report.md` 是给人读的汇总，`manifest.json` 记录每个文件多大、脱敏规则各替换了多少次。所有文字在写进包之前都会过一遍脱敏，用户名、邮箱、链接里的令牌不会出现在里面。
- **诊断页多了三项检查**：WebView2 运行时（缺失时窗口根本画不出来，Windows 10 上最常见）、系统位数（32 位无法注入）、.NET Framework 4.8（国服启动器需要）。检查不通过时，行下面直接写「怎么解决」。
- **详细注入日志开关**：设置 → 通用 → Diagnostics →「Verbose patcher logging」。皮肤提示应用了但游戏里没变化时，打开它、复现一次，注入器的完整输出会写进日志，下次随诊断包一起发出来。
- **「清理残留注入」按钮**：国服英雄与皮肤顶部控制栏。它不看当前有没有开注入，直接找 `cslol-inj.exe` 并结束掉，需要时会弹一次管理员授权。残留的注入器会让下一局游戏起不来，删过 VinciSkin 文件夹、或者没有正常停止注入的人最容易碰到。
- 错误提示底部多了「复制详情」和「生成诊断包」两个动作：「复制详情」给出错误码和那句话，「生成诊断包」当场打开诊断包，不用再跑回设置页。

### 修复

- **提示应用成功、游戏里却没变化**：现在会先确认注入器开没开、游戏开没开，再据实说结果；没开时给一个「启动注入」的入口，而不是一律弹成功。
- **注入器状态不准**：VinciSkin 重启以后，之前启动的注入器会被当成「未运行」，按钮一直停在「启动注入」。现在只要 `cslol-inj.exe` 还活着就算运行，按钮会变成「停止注入」，点它可以结束掉这个外部进程。
- **游戏已经在运行**时，状态行会直接写「注入没开 · 游戏已经在跑，这一局不会变」，不再让人以为点一下还能救回来。注入相关的报错也都换成了中文。
- 诊断页的 Windows 版本按 build 号显示成 Windows 11（build 26200），不再沿用注册表里那个 Windows 10。
- 「打开日志文件」在资源管理器里直接选中这份日志，而不是只打开目录。
- 取消管理员授权时，提示是一句中文，而不是英文的系统错误。

### 改动

- **诊断页和设置页全中文**。标题栏的铃铛、听诊器、齿轮、更多四个图标后面补上了文字，窗口窄时自动只留图标。
- **日志更好对时间**：时间戳改成本地时间，每行带 `run` / `session` / `game` 编号，一次启动、一次注入、一局游戏的行可以直接挑出来。单文件到 5 MB 轮转，日志目录总量 50 MB，启动时清掉 7 天前的文件。
- **日志脱敏**：用户名、`%APPDATA%` 之类的路径、邮箱、链接里的令牌，在写进文件之前就替换成占位符，日志可以直接贴到公开的地方。
- 启动阶段、panic 和前端错误现在都会留下记录，程序在窗口出现之前挂掉也能看出停在哪一步。

### 安装

下载 zip，解压后覆盖旧版的 `VinciSkin.exe`。设置、日志和已经装好的 mod 都不动。

### 已知问题

- Windows 10 上缺少 WebView2 时，程序仍然是静默不出现窗口（无窗口的 `--report` 还没做）。装好运行时之后可以正常启动，诊断页现在能查出这一项。
- 注入必须在 League 启动之前开始。游戏起来之后再开注入无效，这是 loader 的工作方式，界面会提示。
- 诊断包默认不带 League 游戏日志，需要手动勾选。
